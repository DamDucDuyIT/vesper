Vesper v1.0.0 cho macOS (Apple Silicon & Intel)

Giải mã 60 GB bí ẩn trong mục Documents của máy Mac.

macOS gom toàn bộ thư mục ẩn ~/.* và hàng trăm nghìn file nhỏ node_modules vào Documents nhưng lại giấu chúng khỏi Finder. Vesper soi rọi và dọn sạch.

Tại sao mục Documents báo 60GB nhưng Large Files lại trống trơn?

Công cụ System Settings > Storage mặc định của macOS được thiết kế cho người dùng cơ bản, vô tình tạo ra những "điểm mù" khổng lồ cho lập trình viên và power user.

✕

System Settings mặc định

  • ⚠️
    Ẩn toàn bộ thư mục dấu chấm (.): Mọi thư mục ~/.cache, ~/.npm, ~/.gradle, ~/.cargo bị ẩn trong File Browser nhưng vẫn bị cộng dung lượng vào Documents.
  • ⚠️
    Bỏ qua hàng vạn file nhỏ: Large Files chỉ tìm file lẻ > 50MB. Một thư mục node_modules chứa 120.000 file 5KB (tổng 20GB) hoàn toàn vô hình.
  • ⚠️
    Đánh đồng System Data: Dữ liệu tạm, logs ứng dụng và cache SDK Xcode bị gộp chung vào "System Data" mà không cho phép bấm vào để xem chi tiết hay xóa.
✓

Giải pháp của Vesper

  • ✦
    Soi rọi 100% thư mục ẩn: Tự động bóc tách từng folder ~/.*, phân loại rõ ràng cache của npm, gradle, pyenv, ollama, gemini...
  • ✦
    Quét sâu cây thư mục & Build Artifacts: Tìm ra mọi cụm node_modules, .venv, target, .next phân bổ trên máy bằng thuật toán cắt tỉa đa luồng.
  • ✦
    Đo lường APFS vật lý thực tế: Tính toán chính xác dung lượng đĩa chiếm dụng bằng du -skx, không bị báo ảo bởi iCloud stub files.
Thủ phạm ngầm

Bóc trần 4 "hố đen" nuốt dung lượng trên macOS

Vesper phân nhóm thông minh giúp bạn nhận biết ngay thư mục nào an toàn để xóa.

🕵️ ~/.*

Thư mục ẩn trong Home

Các thư mục .cache, .npm, .gradle, .cargo, .local sinh ra âm thầm khi bạn chạy lệnh CLI. Xóa an toàn để lấy lại hàng chục GB.

📦 node_modules

Code & Build Artifacts

Mỗi project Node/Python/Rust cũ chứa hàng vạn file phụ thuộc. Vesper định vị tất cả node_modules, .venv, target nằm rải rác trong máy.

🧹 Library/Caches

Bộ nhớ đệm & Xcode

~/Library/Caches, logs hệ thống, và Xcode/DerivedData phình to sau mỗi lần biên dịch ứng dụng. Giải phóng ngay để hạ thấp System Data.

🐘 ≥ 100MB

File lớn & AI Models

Các file mô hình local (Ollama .gguf), image Docker, file .dmg cài đặt cũ nằm sâu trong thư mục ẩn mà Spotlight bỏ qua.

Triết lý thiết kế

Xây dựng theo chuẩn Desktop Native, không "AI Slop"

Không quảng cáo, không đăng ký định kỳ, không thu thập dữ liệu cá nhân.

🎨 macOS HIG Chuẩn mực

Tận dụng NSVisualEffectView kính mờ, đèn giao thông tự nhiên, phông chữ SF Pro Display và số liệu tabular-nums mượt mà chống giật số khi quét thời gian thực.

⚡ Đo lường APFS Siêu tốc

Kết hợp /usr/bin/du -skx chạy song song đa luồng và stat.blocks * 512, đảm bảo tốc độ tối đa của ổ SSD Apple Silicon.

🛡️ An toàn Tuyệt đối

Đánh giá mức độ rủi ro (🟢 Safe, 🟡 Caution, 🔴 Careful) trước khi thao tác. Hỗ trợ đưa vào Thùng rác (Trash) trước khi chọn xóa vĩnh viễn.
